Computer science book catalog and covers

The archive contains 100 JPEG covers in database order.
The book ID determines the filename. ID 1 uses book-001.jpg.

To install this catalog, extract the archive and merge the included
FrontEnd folder into your existing Flask project. The included files are:

  FrontEnd/database/books.json
  FrontEnd/static/covers/book-001.jpg through book-100.jpg

This catalog uses IDs 1–100, so installing it replaces the active catalog
and any existing cover images with the same names. If you want to keep
both catalogs, keep a separate copy of the project for each catalog.

Prices and stock are sample data. The cover-index.csv lists each catalog
ISBN and the image source. Some images are from other formats or regional
printings of the same book.
